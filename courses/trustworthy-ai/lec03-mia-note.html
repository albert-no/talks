Membership Inference Attacks

Welcome to Lecture 3 of Trustworthy AI. Today we study the most basic privacy attack on a trained model: deciding whether one specific record was part of its training set.

Key takeaway: Membership inference is the practical unit test for privacy.

Contents

Eight steps: the question, the 2008 genome attack that started the field, the basic loss-threshold attack, shadow models, stronger likelihood-ratio attacks, what it means for differential privacy, modern foundation models, and defenses.

Key takeaway: From one yes-or-no question to a full audit-and-defend toolkit.

01 — The Question

First section. We frame the single question every membership attack answers, who asks it, and what the attacker gets to see.

Key takeaway: Membership alone can be the secret.

One Yes-or-No Question

A membership inference attack, or MIA, takes a trained model and one record, and decides whether that record was used during training. Picture two worlds: one where record $x$ was in training, one where it was held out. The attacker sees only the resulting model and must guess which world produced it. Nothing fancier than in-or-out, and the rest of the lecture is about how loudly that one bit leaks.

Key takeaway: MIA asks only whether a record was in the training set.

Definitions

The membership-inference game. Fix a data distribution $\mathcal{D}$, a (possibly randomized) training algorithm $\mathcal{M}$, a dataset $D$ of $n$ records, and a target record $x \notin D$. The challenger flips a fair bit $b \in \{0,1\}$ and trains

$\theta = \mathcal{M}(D \cup \{x\})$ if $b = 1$ (the "in" world),   $\theta = \mathcal{M}(D)$ if $b = 0$ (the "out" world).

The adversary $\mathcal{A}$ receives the model $\theta$ (or query access to it) together with the target $x$, and outputs a guess $\hat b = \mathcal{A}(\theta, x) \in \{0,1\}$.

Definition (membership advantage). $$\mathrm{Adv}(\mathcal{A}) \;=\; \bigl|\Pr[\mathcal{A}(\theta,x)=1 \mid b=1] \;-\; \Pr[\mathcal{A}(\theta,x)=1 \mid b=0]\bigr|.$$ $\mathrm{Adv}=0$ means the adversary does no better than a coin flip; $\mathrm{Adv}=1$ means it decides membership perfectly. Every attack in this lecture is an instance of $\mathcal{A}$, and every defense is an attempt to keep $\mathrm{Adv}$ small for all $\mathcal{A}$.

(Game and definition as in the privacy-course treatment, courses/privacy/lectures/04-mia/mia1-foundations.html, which this lecture follows throughout.)

Let $P_1$ denote the distribution of the trained model $\theta$ in the world $b=1$ (over the randomness of $\mathcal{M}$), and $P_0$ its distribution in the world $b=0$. The attack is a binary hypothesis test between $H_0: \theta \sim P_0$ and $H_1: \theta \sim P_1$. Define $$\mathrm{TPR}(\mathcal{A}) = \Pr[\mathcal{A}=1 \mid b=1], \qquad \mathrm{FPR}(\mathcal{A}) = \Pr[\mathcal{A}=1 \mid b=0].$$

Theorem & proof

Proposition (three faces of advantage). For any adversary, with $b$ uniform, $$\mathrm{Adv}(\mathcal{A}) = |\mathrm{TPR} - \mathrm{FPR}| = \bigl|2\Pr[\hat b = b] - 1\bigr|.$$

Proof. The first equality is the definition of advantage, since $\Pr[\mathcal{A}=1\mid b=1] = \mathrm{TPR}$ and $\Pr[\mathcal{A}=1\mid b=0] = \mathrm{FPR}$. For the second: with $b$ a fair coin, $$\Pr[\hat b = b] = \tfrac12 \Pr[\hat b =1 \mid b=1] + \tfrac12 \Pr[\hat b = 0 \mid b=0] = \tfrac12\bigl(\mathrm{TPR} + 1 - \mathrm{FPR}\bigr),$$ so $2\Pr[\hat b = b] - 1 = \mathrm{TPR} - \mathrm{FPR}$. $\blacksquare$

So "guessing accuracy above 50%" and "TPR exceeding FPR" are the same quantity in different units. (Verified against mia1-foundations.html, Proposition 2.)

The Simplest Leak

Membership is the simplest thing an attacker can ask and the easiest to measure cleanly. If a model fails this test, it almost certainly leaks more.

Key takeaway: Pass the membership test before claiming any stronger privacy.

Theorem & proof

The converse direction can be made precise: stronger attacks imply membership attacks, so bounding membership advantage bounds them. The cleanest instance is verbatim extraction from a language model.

Proposition (extraction is a low-FPR membership test). Split a record $x = (p_x, s_x)$ into a prefix and a suffix, and let $\mathcal{A}_{\mathrm{ext}}(x,\theta) = \mathbf{1}[\,f_\theta(p_x) = s_x\,]$, where $f_\theta$ is greedy decoding. Suppose the suffix has conditional min-entropy $H_\infty(s_x \mid p_x) = h$ under the non-member law, and that $\theta$ is independent of $s_x$ given $x \notin D$. Then $$\mathrm{FPR}(\mathcal{A}_{\mathrm{ext}}) \le 2^{-h}, \qquad \mathrm{Adv}(\mathcal{A}_{\mathrm{ext}}) \ge \mathrm{TPR} - 2^{-h}.$$

Proof. Condition on $x \notin D$; then $\theta$ carries no information about $s_x$. Writing $c = f_\theta(p_x)$ for the emitted continuation, $$\Pr[\,c = s_x \mid x \notin D\,] = \mathbb{E}\bigl[\Pr[s_x = c \mid p_x]\bigr] \le \max_{c'} \Pr[s_x = c' \mid p_x] = 2^{-h}.$$ The advantage bound follows from $\mathrm{Adv} = |\mathrm{TPR} - \mathrm{FPR}| \ge \mathrm{TPR} - 2^{-h}$. $\blacksquare$

Read contrapositively: if every membership attack has advantage at most $\eta$, then verbatim extraction of any high-entropy suffix succeeds with probability at most $\eta + 2^{-h}$. That is the formal sense in which membership is the unit test: it is the weakest question, so passing it caps this family of stronger leaks. (Statement and proof verified against courses/privacy/lectures/04-mia/mia5-llm.html, Proposition 8.)

Why Membership Alone Hurts

If a model was trained only on cancer patients, then confirming that Alice is a member directly reveals her diagnosis. No record needs to be reconstructed for real harm.

Key takeaway: When the cohort is sensitive, membership leaks the secret.

Definitions

Formally: if inclusion in the training cohort is determined by a sensitive predicate — $D$ consists of records of people satisfying $s(\cdot) = 1$ (a diagnosis, an app's user base, a demographic) — then the membership bit $b$ is the value $s(\text{Alice})$. An attack with advantage $\mathrm{Adv}$ against membership is an attack with the same advantage against the sensitive attribute itself. Nothing about Alice's record needs to be reconstructed.

Background & further reading

This is not hypothetical: the first membership inference attack, Homer et al. 2008 on the published averages of genome studies, was exactly this scenario. Since those cohorts were defined by disease status, membership revealed diagnosis. Section 02 walks through the attack, its power, and its policy impact.

  • Homer et al., "Resolving Individuals Contributing Trace Amounts of DNA to Highly Complex Mixtures Using High-Density SNP Genotyping Microarrays", PLoS Genetics 2008 — the original genomic membership inference attack.

When Membership Is the Secret

Why does a single yes/no bit matter? Because the dataset's name often is the sensitive fact. Being in a disease study means having the disease; being in a trial means having the diagnosis; being in a chat-log corpus means you wrote one of the messages; being in a pirated-book training set is the evidence in a copyright claim.

Key takeaway: Membership alone can be the whole privacy harm.

Background & further reading

  • The copyright instance is live: membership-inference-style evidence has been discussed in training-data litigation against LLM developers; "MIA in the Courtroom" in section 07 returns to it. The genomics instance is the one that actually changed policy: see "Impact: NIH Pulled the Data" in section 02.

Who Asks, and Why

Three very different customers want this one bit: auditors use it to measure how much a model leaks, courts want it in copyright disputes over training data, and attackers use it to find members before extracting them. Same question, three stakes.

Key takeaway: Membership inference serves privacy audits, litigation, and extraction alike.

The Threat Model

Two access levels: black-box, where the attacker only queries inputs and reads outputs, and white-box, where weights and gradients are also visible. Most attacks need only black-box access.

Key takeaway: Black-box access is usually enough to attack.

Definitions

White-box access. The adversary receives the parameters themselves: $\hat b = \mathcal{A}(\theta, x)$. Gradients, activations, and internal statistics are all available.

Black-box access. The adversary may only query the model as an oracle: $\hat b = \mathcal{A}^{f_\theta}(x)$, submitting inputs and observing outputs. Black-box access comes in decreasing grades:

  • confidence vector — the full softmax output $f_\theta(x) \in \Delta^{k-1}$;
  • top confidence — only $\max_y f_\theta(x)_y$ (or the top few);
  • label only — just $\arg\max_y f_\theta(x)_y$ (attacked in §04, "Label-Only Attacks").

Every attack in this lecture except the white-box variants of §04 operates in the black-box confidence-vector model or below.

A Score and a Threshold

Every attack reduces to the same shape: compute a score for the record, compare it to a threshold, and call it a member or non-member. The art is in choosing a good score.

Key takeaway: All membership attacks are a score plus a threshold.

Definitions

Score-threshold attack. A score is a function $s(x, \theta) \in \mathbb{R}$; the attack at threshold $\tau$ is $$\hat h_\tau(x) = \mathbf{1}\bigl[\, s(x,\theta) \ge \tau \,\bigr],$$ declaring "member" when the score clears the bar. Sweeping $\tau$ traces out the operating points $$\mathrm{TPR}(\tau) = \Pr[\, s \ge \tau \mid b=1\,], \qquad \mathrm{FPR}(\tau) = \Pr[\, s \ge \tau \mid b=0\,],$$ whose graph $\{(\mathrm{FPR}(\tau), \mathrm{TPR}(\tau)) : \tau \in \mathbb{R}\}$ is the attack's ROC curve (used from "TPR at Low FPR" onward).

Which score is best? The Neyman–Pearson lemma answers exactly: the optimal score is the likelihood ratio of the two worlds. Statement and full proof at "The Likelihood Ratio" in §04; the whole arc of this lecture (loss → calibrated loss → LiRA) is a sequence of increasingly good approximations to it.

02 — The First Attack

Second section. Before any neural network was attacked, a 2008 genomics paper showed that published cohort averages reveal who was in the study. We walk through that attack in full, because every later membership inference attack is the same template.

Key takeaway: Membership inference predates deep learning; Homer et al. 2008 is the original.

Before Neural Nets: The Genome Leak

Before there were neural networks to attack, there were genome-wide association studies. In 2008 they published the average allele frequency of their cohort at every SNP, openly, on the assumption that an average over a thousand people hides each one. A forensics paper by Homer and colleagues showed that assumption was wrong: from those averages plus one person's genome you can tell whether that person was in the study.

Key takeaway: The first membership inference attack targeted published averages, not a model.

Background & further reading

  • Homer et al., "Resolving Individuals Contributing Trace Amounts of DNA to Highly Complex Mixtures Using High-Density SNP Genotyping Microarrays", PLoS Genetics 4(8): e1000167 (2008) — open access. The paper is framed as forensics (finding one contributor in a DNA mixture); the GWAS consequence is stated in the abstract: "composite statistics across cohorts, such as allele frequency or genotype counts, do not mask identity within genome-wide association studies."
  • The rigorous version of this block, with Lemma/Theorem/proofs, is the Homer section of courses/privacy/lectures/04-mia/mia1-foundations.html.

Genomics in 60 Seconds

All the biology we need: a SNP is a single position in the genome where people differ, an array reads about half a million of them per person, and a study's published "allele frequency" at a SNP is just the column average of that letter across its participants. Individual rows were never released.

Key takeaway: The study published column averages; the attack works from those alone.

Definitions

For SNP $j$ and participant $k$ let $Y_{k,j} \in \{0,1\}$ indicate the minor allele (haploid simplification; real genotypes take values in $\{0, \tfrac12, 1\}$). The published statistic is the cohort frequency $M_j = \frac1n \sum_{k=1}^n Y_{k,j}$. The population frequency $\mathrm{Pop}_j$ comes from a public reference panel (HapMap in the paper).

Homer's Statistic

Here is the whole idea in one line. At each SNP put three points on the 0-to-1 axis: the population frequency, the study's frequency, and Alice's own letter. Measure her distance to each. If she sits nearer the study than the population, that SNP whispers "she was in it." The statistic $D_j$ is just that comparison with a sign: positive means "closer to the study", negative means "closer to everyone". Walk through the example on the slide: population 0.30, study 0.40, Alice 1, so distances 0.70 and 0.60 and $D_j = +0.10$.

Key takeaway: $D_j$ is distance-to-everyone minus distance-to-the-study; positive leans "in".

Definitions

Homer distance statistic (paper's sign convention, Fig. 1): $D_j = \lvert Y_j - \mathrm{Pop}_j \rvert - \lvert Y_j - M_j \rvert$, where $Y_j \in \{0, \tfrac12, 1\}$ is Alice's genotype at SNP $j$ (haploid $\{0,1\}$ in the idealized model), $M_j$ the mixture or study allele frequency, and $\mathrm{Pop}_j$ the reference-population frequency. The paper's test is a one-sample $t$-test on $\{D_j\}_{j=1}^m$ against mean zero. (The privacy-course mia1 deck uses the opposite sign, $\lvert Y - M\rvert - \lvert Y - \mathrm{Pop}\rvert$, so its member mean is negative; the two are equivalent.)

Why One SNP Says Nothing

Let us make the whisper precise. For a 0/1 letter the absolute values collapse and $D_j$ factors into two pieces: how far the study average drifted from the population, times the sign of Alice's letter. If Alice is outside the study those two pieces are independent, and the drift is centred, so $D_j$ averages to zero. If she is inside, she is one of the $n$ people in the average, and her own letter drags the drift toward her sign: the mean is $2p(1-p)/n$, about four ten-thousandths at $n = 1{,}000$. The noise is the same in both worlds, about $0.014$. Signal-to-noise of $0.03$: a single SNP tells you nothing.

Key takeaway: Per SNP, membership shifts the mean by $2p(1-p)/n$ against noise $\sqrt{p(1-p)/n}$: hopeless alone.

Theorem & proof

Per-SNP mean and variance (idealized model: independent SNPs, $\mathrm{Pop}_j = p_j$ known exactly, haploid $Y \in \{0,1\}$). Under $H_0$ (Alice not in the cohort), $\mathbb E[D_j] = 0$. Under $H_1$ (Alice one of the $n$), $\mathbb E[D_j] = 2p_j(1-p_j)/n$ in the paper's sign convention. In both cases $\mathrm{Var}(D_j) = p_j(1-p_j)/n$ to leading order. Proof sketch: for $Y \in \{0,1\}$ and $a \in [0,1]$, $\lvert Y - a\rvert = a + Y(1-2a)$, so $D_j = (M_j - p_j)(2Y_j - 1)$; under $H_0$ the two factors are independent and $M_j - p_j$ is centred; under $H_1$ write $M_j = \tfrac1n Y_j + \tfrac{n-1}{n}\bar Y_{-j}$ and use $Y_j^2 = Y_j$. The slide's numbers take $p(1-p) = 0.2$: tilt $2(0.2)/1000 = 4\times10^{-4}$, standard deviation $\sqrt{0.2/1000} \approx 0.014$, ratio $\approx 0.028$.

One SNP Whispers, 500,000 Shout

Why does a single $D_j$ say nothing? If Alice is not in the study, her letter and the study average are independent, and $D_j$ averages to zero. If she is, she is one of the $n$ people inside that average, and her own contribution tilts $D_j$ slightly positive, by about $2p(1-p)/n$. At $n = 1{,}000$ that is four ten-thousandths, against random noise thirty times larger. The left bells on the slide are essentially one bell. Now sum over the array. The tilt adds up linearly in the number of SNPs, the noise only like its square root, so the bells separate. The gap grows like the square root of SNPs over cohort size: a study twice as large is exactly cancelled by an array twice as dense.

Key takeaway: Each SNP is hopeless alone; 500,000 of them turn a 0.03 signal-to-noise into a clean separation.

Background & further reading

The per-SNP calculation and the power analysis behind the two bells are spelled out in the next two entries.

How Many SNPs Are Enough?

Now the arithmetic of summing. Add $m$ statistics: the tilt grows like $m$, the noise like $\sqrt{m}$, so the standardized gap between the two bells is $\mu = 2\sqrt{m\bar v/n}$. Read the table: at a false-positive level of one in a million, a thousand-person cohort needs about 28,000 SNPs to catch half its members and about 39,000 to catch eight in ten. Ten times the cohort needs ten times the SNPs, roughly 390,000. A standard array reads 500,000. Stress that these are idealized-model numbers, not the paper's reported values; the next slide has those.

Key takeaway: The gap grows like $\sqrt{m/n}$; the SNP budget scales linearly with cohort size, and arrays already have enough.

Theorem & proof

Power of the aggregated test. With $S = \sum_{j=1}^m D_j$ standardized by its null deviation, the level-$\alpha$ test has asymptotic power $\pi = \Phi(\mu - z_{1-\alpha})$ with $\mu = 2\sqrt{m\bar v/n}$, $\bar v = \frac1m\sum_j p_j(1-p_j)$. Sketch: the Lindeberg CLT applies ($\lvert D_j\rvert \le 1$, $m \to \infty$); null mean 0 and variance $m\bar v/n$; alternative mean $2m\bar v/n$ with variance unchanged to leading order. Corollary: $m \ge n(z_{1-\alpha} + z_{1-\beta})^2/(4\bar v)$ SNPs suffice for power $1-\beta$: about $28{,}000$ at $n = 1{,}000$, $\alpha = 10^{-6}$, power $0.5$, $\bar v = 0.2$; about $39{,}000$ for power $0.8$; about $390{,}000$ at $n = 10{,}000$. Full statements and proofs: privacy course mia1 deck, Lemmas 1–2, Proposition 1, Theorem 1, Corollary 1. These are idealized-model numbers, not values reported by Homer et al.

What the Paper Reported

Homer's group did not stop at simulation. They pooled real DNA into mixtures, ran them on three commercial genotyping arrays, and tested every person in the HapMap reference set against each mixture. Everyone in the mixture scored high, everyone outside scored near zero, with no overlap in mixtures of 40 or more people, including one where a single person contributed a tenth of one percent. Explain the table's second column before reading it: a person's share is the fraction of the pooled DNA that came from them, so in a 1,000-person GWAS cohort every member is a 0.1% share, and in a 100-person study each is 1%. "Smallest share detected" is the smallest such fraction at which the test still separates members from non-members at $p \lt 10^{-6}$. Read the rows as cohort sizes: ten to twenty-five thousand SNPs already detect a member of a cohort of about a hundred; fifty thousand SNPs detect a member of a thousand-person cohort when the array noise is low; the full half-million SNPs go below that. The smaller the detectable share, the larger the study whose published averages leak membership, which is why the standard 500,000-SNP array made every ordinary GWAS vulnerable.

Key takeaway: "Share" is one person's fraction of the pool; the attack detects a 0.1% share, i.e. one member of a 1,000-person cohort, with zero false positives.

Impact: NIH Pulled the Data

The consequence was immediate. Within days of publication the NIH removed aggregate genotype data from open access and moved it behind controlled-access agreements; the Wellcome Trust followed. It was the first time a membership inference attack changed policy, and it set the precedent we will keep meeting: aggregation is not anonymization.

Key takeaway: One paper moved genome-wide summary data from open to controlled access.

03 — The Basic Attack

Third section. The core mechanism: models fit the points they saw, so overfitting leaves a measurable fingerprint we can threshold on.

Key takeaway: Overfitting is the engine that powers membership inference.

Models Fit What They Saw

Training drives loss down on the training points, so on average train loss is below test loss. A member therefore tends to have lower loss than a stranger.

Key takeaway: Lower loss is the basic tell of membership.

Definitions

Per-example loss. $\ell(\theta, z) \in [0, B]$ is the loss of model $\theta$ on record $z = (x,y)$ — for classification, typically the cross-entropy $\ell(\theta,z) = -\log f_\theta(x)_y$, clipped or bounded by $B$.

Train and population risk. For a training set $S \sim \mathcal{D}^n$ and trained model $\theta_S$: $$R_{\mathrm{train}} = \mathbb{E}_{S,\, z \sim S}\bigl[\ell(\theta_S, z)\bigr], \qquad R_{\mathrm{pop}} = \mathbb{E}_{S,\, z \sim \mathcal{D}}\bigl[\ell(\theta_S, z)\bigr],$$ where $z \sim S$ means a uniformly random training record and $z \sim \mathcal{D}$ a fresh one.

Generalization gap. $\Delta = R_{\mathrm{pop}} - R_{\mathrm{train}}$ — the average amount by which the model fits its own records better than strangers. This is the quantity the slide's "two averages" gesture at, and the exact currency of the Yeom theorem in "A Theory Anchor". (Notation as in mia3-theory.html, Definition 3.)

Loss Is the Score

The simplest score is the per-example loss itself. The whole attack is three lines: query the model for the loss, compare it to a threshold, and return member if it is small. Low loss means guess member, high loss means guess non-member. No training and no internals are required.

Key takeaway: Per-example loss plus a threshold is already an attack.

Definitions

Loss-threshold attack. With score $s(x,\theta) = -\ell(\theta, (x,y))$ (negated so that higher means "more member-like"), the attack is $$\mathcal{A}_\tau(x, y) = \mathbf{1}\bigl[\,\ell(\theta,(x,y)) \le \tau\,\bigr].$$ It requires one query, the true label $y$, and no knowledge of the training pipeline. The threshold $\tau$ can be set to the population average loss, or tuned on models the attacker trains herself (§03).

Pseudocode made precise: given oracle access to $f_\theta$ and the labeled record $(x,y)$,

  1. query once: $p \leftarrow f_\theta(x)$;
  2. compute the loss: $\ell \leftarrow -\log p_y$;
  3. return "member" iff $\ell \le \tau$.

This is $\mathcal{A}_\tau$ from "Loss Is the Score". Its ROC curve is exactly the curve traced by sweeping $\tau$; all later attacks change only step 2 — the score.

The Two Bells

Plot member losses and non-member losses as two distributions. Members sit lower, but the two bells overlap, and that overlap is exactly the attacker's error rate.

Key takeaway: The overlap of the two loss distributions sets the attack's accuracy.

Definitions

Let $P_1$ and $P_0$ now denote the distributions of the adversary's observation (e.g. the loss of the target record) in the member and non-member worlds — the two bells. The right notion of "overlap" is total variation distance: $$\mathrm{TV}(P_1, P_0) = \sup_{S} \bigl| P_1(S) - P_0(S) \bigr|,$$ the largest disagreement the two laws assign to any event.

Theorem & proof

Proposition (the overlap is exactly the best advantage). $$\sup_{\mathcal{A}} \mathrm{Adv}(\mathcal{A}) = \mathrm{TV}(P_1, P_0),$$ and the supremum is attained by $\mathcal{A}^*(t) = \mathbf{1}[\, p_1(t) \gt p_0(t)\,]$, where $p_1, p_0$ are the densities of $P_1, P_0$.

Proof. (Upper bound.) Any adversary defines the event $S_{\mathcal{A}} = \{t : \mathcal{A}(t) = 1\}$, so $$\mathrm{Adv}(\mathcal{A}) = |P_1(S_{\mathcal{A}}) - P_0(S_{\mathcal{A}})| \le \sup_S |P_1(S) - P_0(S)| = \mathrm{TV}(P_1,P_0).$$ (Achievability.) Take $S^* = \{t : p_1(t) \gt p_0(t)\}$. Then $$P_1(S^*) - P_0(S^*) = \int_{S^*} \bigl(p_1(t) - p_0(t)\bigr)\,dt = \mathrm{TV}(P_1, P_0),$$ the last equality because $\int (p_1 - p_0) = 0$ splits into equal positive and negative parts, and $S^*$ collects the entire positive part. $\blacksquare$

So "overlap sets the accuracy" is literal: the best achievable guessing accuracy is $\tfrac12(1 + \mathrm{TV}(P_1,P_0))$, by the identity in "One Yes-or-No Question". (Verified against mia1-foundations.html, Proposition 3.)

Overfitting Drives MIA

The wider the train-test gap, the further apart the two bells, and the easier this attack. But note the caveat: a small gap weakens the loss attack without guaranteeing safety — stronger attacks in section five still find members of well-generalizing models.

Key takeaway: Overfitting makes the attack easy; its absence is not a guarantee.

Theorem & proof

The caveat is a theorem, not a hedge. The folklore claim "$\mathrm{Adv} \le \Delta$" (no gap, no leak) is false:

Proposition (zero gap, perfect attack). There is a loss distribution pair with generalization gap $\Delta = 0$ and $\sup_{\mathcal{A}} \mathrm{Adv}(\mathcal{A}) = 1$.

Proof (explicit construction). Suppose members receive loss $0$ or $1$ with probability $\tfrac12$ each, while non-members always receive loss exactly $\tfrac12$. The average member loss is $\tfrac12$ and the average non-member loss is $\tfrac12$, so $\Delta = \tfrac12 - \tfrac12 = 0$. Yet the test $\hat b = \mathbf{1}[\,\ell \ne \tfrac12\,]$ has $\mathrm{TPR} = 1$ and $\mathrm{FPR} = 0$, hence $\mathrm{Adv} = 1$: membership is decided perfectly while the train-test gap is zero. $\blacksquare$ (derivation: course notes — construction as in mia3-theory.html, which also gives the converse counterexample: positive gap with zero advantage for the threshold attack.)

What is true is the exact equality of this section's "A Theory Anchor": the gap governs one particular attack, not the supremum over all attacks. Averages can match while distributions differ — and attacks exploit distributions.

Confidence Works Too

When the true label is hidden, use the model's confidence instead. Members get sharper outputs, so the top predicted probability, or its gap to the runner-up, works as a score — the simple confidence-threshold baseline is due to Salem and colleagues' ML-Leaks.

Key takeaway: Confidence substitutes for loss when labels are unavailable.

Slide figure: The slide shows Salem et al. Fig. 11: histograms of the maximal posterior for members, non-members, and random inputs on CIFAR-100 and News; members pile up near 1.0, which is exactly the confidence signal the attack thresholds.

Definitions

Confidence scores. $c(x) = \max_y f_\theta(x)_y$ (top softmax probability), or the margin $c_{(1)}(x) - c_{(2)}(x)$ between the top two. When the model's prediction is correct ($\arg\max_y f_\theta(x)_y = y$), thresholding $c$ is equivalent to thresholding the cross-entropy loss, since $\ell = -\log c$ is a decreasing bijection of it — so the two scores order records identically on correctly-classified points.

Background & further reading

  • Salem, Zhang, Humbert, Berrang, Fritz, Backes, "ML-Leaks: Model and Data Independent Membership Inference Attacks and Defenses on Machine Learning Models", NDSS 2019 — showed that relaxing Shokri et al.'s assumptions (many shadows, same data distribution, same architecture) down to a single confidence-threshold baseline preserves most of the attack's power.

A Theory Anchor

Yeom and colleagues proved the threshold attack is no accident: for their loss-threshold attacker, membership advantage grows in step with the train-test gap. Their formal analysis shows overfitting is sufficient for membership leakage, though — importantly — not necessary.

Key takeaway: The loss attack is provably tied to overfitting.

Slide figure: The slide reproduces Yeom et al. Fig. 2: the empirical advantage of the threshold adversary plotted against the generalization ratio for regression and tree models on Eyedata, IWPC, and Netflix, and for deep CNNs on MNIST, CIFAR-10, and CIFAR-100, together with the theoretical curve; advantage grows with the gap as the theorem predicts.

Definitions

Yeom's membership experiment. Sample $S \sim \mathcal{D}^n$ and train $\theta_S$. Flip a fair bit $b$; if $b=1$ draw $z$ uniformly from $S$, if $b=0$ draw $z \sim \mathcal{D}$ fresh. The adversary sees $(z, \theta_S)$ and guesses $\hat b$. Losses are bounded: $\ell(\theta, z) \in [0, B]$.

Adversary 1 (loss-proportional coin). Output "member" ($\hat b = 1$) with probability $1 - \ell(\theta_S, z)/B$ — i.e. flip a coin biased toward "member" exactly when the loss is small.

Theorem & proof

Theorem (Yeom et al. 2018, Theorem 2). The advantage of Adversary 1 is exactly the normalized generalization gap: $$\mathrm{Adv}(\mathcal{A}_1) = \frac{\Delta}{B}, \qquad \Delta = R_{\mathrm{pop}} - R_{\mathrm{train}}.$$

Proof. Condition on each world and use linearity of expectation: $$\Pr[\hat b = 1 \mid b=1] = \mathbb{E}_{S,\, z\sim S}\Bigl[1 - \frac{\ell(\theta_S,z)}{B}\Bigr] = 1 - \frac{R_{\mathrm{train}}}{B},$$ $$\Pr[\hat b = 1 \mid b=0] = \mathbb{E}_{S,\, z\sim \mathcal{D}}\Bigl[1 - \frac{\ell(\theta_S,z)}{B}\Bigr] = 1 - \frac{R_{\mathrm{pop}}}{B}.$$ Subtracting, $\mathrm{Adv}(\mathcal{A}_1) = \bigl(R_{\mathrm{pop}} - R_{\mathrm{train}}\bigr)/B = \Delta/B$. $\blacksquare$

Corollary. $\Delta/B \le \sup_{\mathcal{A}} \mathrm{Adv}(\mathcal{A}) = \mathrm{TV}(P_1, P_0)$ — the gap is a lower bound on the best possible attack, which is why overfitting is sufficient for leakage but (by the previous entry's counterexample) not necessary. (Theorem, proof, and corollary verified against mia3-theory.html, which follows Yeom et al.)

Background & further reading

  • Yeom, Giacomelli, Fredrikson, Jha, "Privacy Risk in Machine Learning: Analyzing the Connection to Overfitting", IEEE CSF 2018 — the formal bridge between generalization and membership leakage; also proves the pure-DP bound quoted in §05.

04 — Shadow Models

Fourth section. We upgrade from a hand-picked threshold to a learned attack, using copycat models whose membership labels we control.

Key takeaway: Build models you understand to learn the membership signal.

One Threshold Is Crude

A single global threshold ignores that classes have different loss scales and inputs differ in difficulty. We would rather train the attack than guess a cutoff.

Key takeaway: A global threshold leaves signal on the table.

Definitions

The two bells of §02 are mixtures: writing $Q_{\mathrm{in}}(z)$ and $Q_{\mathrm{out}}(z)$ for the loss distributions of one specific record $z$ (defined formally in §04), the global bells are $P_1 = \mathbb{E}_z[Q_{\mathrm{in}}(z)]$ and $P_0 = \mathbb{E}_z[Q_{\mathrm{out}}(z)]$. A single threshold is tuned to the mixtures; it cannot be simultaneously right for an easy record (low loss either way) and a hard one (high loss either way). §03 learns a richer decision rule from data; §04 goes all the way to per-record calibration.

The Shadow Idea

You cannot see the target's true members, so Shokri and colleagues build shadow models: models trained like the target on data you own, where you know exactly who is in and who is out.

Key takeaway: Shadow models give you ground-truth membership labels.

Slide figure: The slide reproduces Shokri et al. Fig. 2: the private training set trains the target through the ML API, and k attacker-owned shadow training sets train k shadow models through the same API, so their in/out behavior is known.

Definitions

Shadow assumption. The attacker can train models under the same conditions as the target:

  1. shadow training sets $Z_1, \dots, Z_m$ are drawn from the same distribution $\mathcal{D}$ and have the same size $n$ as the target's;
  2. each shadow $\theta_j = \mathcal{M}(Z_j)$ uses the same training algorithm, with independent randomness;
  3. probe records used to query the shadows are fresh draws.

(As formalized in mia2-shadow.html, Assumption S. In practice each clause degrades gracefully — see "Why It Transfers".)

Background & further reading

  • Shokri, Stronati, Song, Shmatikov, "Membership Inference Attacks against Machine Learning Models", IEEE S&P 2017 — the paper that brought membership inference to machine learning: black-box attacker trains its own "inference model" on shadow outputs to recognize how the target behaves on trained-on versus unseen inputs.

The Shadow Pipeline

Train several shadow models, collect their outputs labeled in or out, and train an attack classifier on those labeled outputs. The classifier learns what a member's output looks like, then transfers that judgment to the target model, without ever touching the target's data.

Key takeaway: Shadow outputs become labeled training data for an attack model that transfers to the target.

Theorem & proof

The pipeline is statistically sound because shadows simulate the game exactly. Let $\Phi(\theta, z)$ be the feature the attack extracts (confidence vector, loss, …), and let $P_1, P_0$ be the feature's laws for members and non-members of the target.

Proposition (shadows sample the true distributions). Under the shadow assumption, for each shadow $j$ with training record $Z_j \ni z$ and fresh probe $z' \notin Z_j$: $$\Phi(\theta_j, z) \sim P_1, \qquad \Phi(\theta_j, z') \sim P_0,$$ independently across $j$.

Proof. The feature is a fixed measurable function of the triple (training set, algorithm randomness, probe record). By clauses (1)–(3) of the assumption, this triple has the same joint law for shadow $j$ as for the target — same $\mathcal{D}^n$, same $\mathcal{M}$, same probe law — so the pushforward law of the feature is the same, namely $P_1$ when the probe is in the shadow's training set and $P_0$ when it is out. Independence across $j$ holds because the shadows use disjoint fresh data and independent randomness. $\blacksquare$

So the labeled dataset $\{(\Phi, \text{in/out})\}$ the pipeline collects is an i.i.d. sample from the very two distributions the attack must distinguish — supervised learning applies off the shelf. (Verified against mia2-shadow.html, Proposition 1.)

What does the attack classifier converge to? Exactly the optimal test.

Theorem (the log-loss minimiser is the likelihood ratio in disguise). Let $p_1, p_0$ be the densities of $P_1, P_0$ and let the membership prior be balanced. The unique minimiser of the population logistic risk $$\mathcal{R}(\mathcal{A}) = \mathbb{E}\bigl[-b \log \mathcal{A}(u) - (1-b)\log(1 - \mathcal{A}(u))\bigr]$$ over measurable $\mathcal{A} : u \mapsto [0,1]$ is $$\mathcal{A}^*(u) = \frac{p_1(u)}{p_1(u) + p_0(u)} = \frac{\Lambda(u)}{1 + \Lambda(u)}, \qquad \Lambda(u) = \frac{p_1(u)}{p_0(u)},$$ which is strictly increasing in the likelihood ratio $\Lambda$. Hence every threshold on the classifier's output is a likelihood-ratio test.

Proof. Condition on the feature $u$. With balanced prior, $\pi(u) = \Pr[b=1 \mid u] = p_1(u)/(p_1(u)+p_0(u))$, and the conditional risk of predicting value $a \in [0,1]$ at $u$ is $$r(a) = -\pi(u)\log a - (1-\pi(u))\log(1-a).$$ Setting $r'(a) = -\pi(u)/a + (1-\pi(u))/(1-a) = 0$ gives $a = \pi(u)$, and $r''(a) \gt 0$ makes it the unique minimum. Minimising pointwise in $u$ minimises the total risk, so $\mathcal{A}^*(u) = \pi(u) = \Lambda(u)/(1+\Lambda(u))$. The map $\Lambda \mapsto \Lambda/(1+\Lambda)$ is strictly increasing, so level sets of $\mathcal{A}^*$ are level sets of $\Lambda$. $\blacksquare$

(Verified against mia2-shadow.html, Theorem 1.) Read with the Neyman–Pearson lemma of §04: the shadow attack, trained to convergence, implements the optimal test for the feature it is given.

Why It Transfers

Because the shadows share the target's architecture and task, they overfit in the same way. The in-versus-out pattern carries across, even when the data is only similar.

Key takeaway: Shared architecture means shared memorization habits.

Theorem & proof

"Only similar" can be quantified. Suppose the shadows produce features distributed as $Q_1, Q_0$ instead of the target's true $P_1, P_0$ (wrong data distribution, wrong architecture, …).

Corollary (misspecification costs at most the TV gap). Fix any test learned from shadows. Its FPR under the target differs from its shadow FPR by at most $\mathrm{TV}(P_0, Q_0)$; its TPR by at most $\mathrm{TV}(P_1, Q_1)$; and its advantage drops by at most $\mathrm{TV}(P_0,Q_0) + \mathrm{TV}(P_1,Q_1)$.

Proof. The learned test defines a fixed acceptance event $S$. Each error rate is the probability of $S$ under one law, and by definition of total variation $|P_i(S) - Q_i(S)| \le \mathrm{TV}(P_i, Q_i)$ for $i \in \{0,1\}$. The advantage is a difference of the two rates, so its change is at most the sum of the two perturbations, by the triangle inequality. $\blacksquare$

(Verified against mia2-shadow.html, Corollary 1.) Transfer succeeds exactly to the degree that the shadow world statistically resembles the target world — which is why matching architecture and data distribution matters, and why even rough matches retain most of the signal.

05 — Stronger Attacks

Fifth section. We move to state-of-the-art attacks that calibrate each record's intrinsic difficulty and we fix how we measure success.

Key takeaway: Strong attacks ask whether the loss is low for this record specifically.

Not All Records Are Equal

Raw loss conflates difficulty with membership: easy records have low loss even as non-members, hard ones high loss even as members. We need to ask, low compared to what?

Key takeaway: Raw loss confuses how hard a record is with whether it was a member.

Slide figure: The slide reproduces Carlini et al. (2022) Fig. 3: member vs. non-member loss histograms for four CIFAR-10 examples arranged as easy/hard to fit by inlier/outlier. Outlier examples separate cleanly while inlier examples overlap, which is why a single global threshold cannot be right for every record.

Definitions

Difficulty, formally: the record-conditional expected loss $\mathbb{E}[\ell(\theta, z) \mid z,\ z \notin \text{train}]$ varies enormously with $z$ — an inlier photo of a common class sits near zero even for models that never saw it; an outlier sits high even for models that did. A global threshold test is optimal only if all records share the same in/out loss laws; they do not. The fix is the next slide's per-record question.

LiRA: Likelihood Ratio Attack

The sharper question is whether the loss is low for this specific record, relative to models that never saw it. Sablayrolles and colleagues show the optimal score is a likelihood ratio between two loss distributions for $x$, in and out. Carlini and colleagues make it practical: train many shadows with the record in and many with it out, fit a Gaussian to each loss distribution, and score by the ratio.

Key takeaway: LiRA scores each record by a per-example in-versus-out likelihood ratio.

Definitions

Logit scaling. LiRA works not with raw confidence $p = f_\theta(x)_y$ but with $\phi(p) = \log\frac{p}{1-p}$, which spreads $(0,1)$ over $\mathbb{R}$ and makes the per-record score distributions approximately Gaussian.

The LiRA statistic. For target record $z$ with observed (logit-scaled) score $\ell^*$ on the target model, fit per-record Gaussians to shadow scores and form $$\Lambda(z) = \frac{\mathcal{N}\bigl(\ell^*;\ \mu_{\mathrm{in}},\ \sigma^2_{\mathrm{in}}\bigr)}{\mathcal{N}\bigl(\ell^*;\ \mu_{\mathrm{out}},\ \sigma^2_{\mathrm{out}}\bigr)},$$ where $(\mu_{\mathrm{in}}, \sigma^2_{\mathrm{in}})$ are the mean and variance of the record's score over shadows trained with $z$, and $(\mu_{\mathrm{out}}, \sigma^2_{\mathrm{out}})$ over shadows trained without. Four numbers per record; the Gaussian family is a modelling choice justified by the logit scaling.

Online LiRA. (1) Train $N$ shadow models on random datasets, half containing $z$; (2) compute the logit-scaled confidence of $z$ under each; (3) fit the two Gaussians; (4) output $\Lambda(z)$ and threshold. Offline LiRA drops the "in" models: score by the one-sided tail $\Lambda_{\mathrm{off}} = \Pr[Z \le \ell^*]$ with $Z \sim \mathcal{N}(\mu_{\mathrm{out}}, \sigma^2_{\mathrm{out}})$, i.e. $\Phi\bigl(z(\ell^*)\bigr)$ — a per-record one-sided $z$-test, which is uniformly most powerful for the one-sided problem by the Karlin–Rubin theorem (statement and proof in mia4-modern.html, Proposition 2). (Definitions verified against mia4-modern.html, Definitions 2–4.)

Per-record score distributions. For a fixed record $z$ and score $s$: $$Q_{\mathrm{in}}(z) = \mathrm{law}\bigl(s(\theta, z)\bigr) \text{ when } z \in \text{training set of } \theta, \qquad Q_{\mathrm{out}}(z) = \mathrm{law}\bigl(s(\theta, z)\bigr) \text{ when } z \notin,$$ randomness over the rest of the training set and the training algorithm. (As in mia4-modern.html, Definition 1.)

Calibrated score. The simplest per-record correction subtracts the record's own out-baseline: $s(\theta,z) - \mathbb{E}_{\theta' :\, z \notin \mathrm{train}(\theta')}[s(\theta',z)]$. The per-record hypothesis test — is the observed score more consistent with $Q_{\mathrm{in}}(z)$ or $Q_{\mathrm{out}}(z)$? — is the fully calibrated version, and is what LiRA implements.

Theorem & proof

Theorem (Neyman–Pearson lemma). Let $P_0, P_1$ have densities $p_0, p_1$ and fix a level $\alpha \in (0,1)$. Among all (possibly randomized) tests $\phi$ with size $\mathbb{E}_0[\phi] \le \alpha$, power $\mathbb{E}_1[\phi]$ is maximised by the likelihood-ratio test $$\phi^*(t) = \begin{cases} 1 & p_1(t) \gt \tau\, p_0(t) \\ \gamma & p_1(t) = \tau\, p_0(t) \\ 0 & p_1(t) \lt \tau\, p_0(t) \end{cases}$$ with $\tau \ge 0$ and $\gamma \in [0,1]$ chosen so that $\mathbb{E}_0[\phi^*] = \alpha$ exactly.

Proof. (1) Calibration. $\alpha \mapsto \Pr_0[p_1 \gt \tau p_0]$ is monotone in $\tau$; pick $\tau$ so the strict-inequality region has $P_0$-mass at most $\alpha$ and the closed region at least $\alpha$, then choose $\gamma$ on the boundary to hit $\alpha$ exactly. (2) Sign trick. For any competing test $\phi$ with values in $[0,1]$, pointwise $$\bigl(\phi^*(t) - \phi(t)\bigr)\bigl(p_1(t) - \tau\, p_0(t)\bigr) \ge 0:$$ where $p_1 \gt \tau p_0$, $\phi^* = 1 \ge \phi$; where $p_1 \lt \tau p_0$, $\phi^* = 0 \le \phi$; on the boundary the second factor vanishes. (3) Integrate. $\int (\phi^* - \phi)(p_1 - \tau p_0) \ge 0$ gives $\mathbb{E}_1[\phi^*] - \mathbb{E}_1[\phi] \ge \tau\bigl(\mathbb{E}_0[\phi^*] - \mathbb{E}_0[\phi]\bigr)$. (4) Size constraint. $\mathbb{E}_0[\phi] \le \alpha = \mathbb{E}_0[\phi^*]$ makes the right side $\ge 0$, so $\mathbb{E}_1[\phi^*] \ge \mathbb{E}_1[\phi]$. $\blacksquare$

(Proof verified against mia1-foundations.html, Theorem 2.) Applied per record with $P_1 = Q_{\mathrm{in}}(z)$, $P_0 = Q_{\mathrm{out}}(z)$: at every false-positive level, no test beats thresholding $\Lambda(z) = q_{\mathrm{in}}/q_{\mathrm{out}}$.

Theorem (Sablayrolles et al. 2019 — loss is the sufficient statistic; sketch). Model trained parameters as a Bayesian posterior $p(\theta \mid z_1,\dots,z_n) \propto \exp\bigl(-\tfrac{1}{T}\sum_i \sigma_i\, \ell(\theta, z_i)\bigr)$, with $\sigma_i$ the membership indicators and $T$ a temperature. Then the posterior probability that $z_1$ was trained on, given $\theta$, depends on $(\theta, z_1)$ only through the calibrated loss $\ell(\theta, z_1) - \tau_p(z_1)$, where $$\tau_p(z_1) = -T \log \int e^{-\ell(t, z_1)/T}\, p(t)\, dt$$ is a per-record threshold; the posterior is a sigmoid-shaped decreasing function of that difference. Consequently the Bayes-optimal membership test is a per-record loss threshold.

Proof sketch. Form the ratio of the posteriors of $\theta$ with $\sigma_1 = 1$ versus $\sigma_1 = 0$; the factors from the other records cancel, leaving $e^{-\ell(\theta,z_1)/T}$ against its normalizing integral $e^{-\tau_p(z_1)/T}$; Bayes' rule converts the log-ratio into a sigmoid. (Statement and sketch verified against mia3-theory.html, Theorems 5–6 and corollary; full proof in the paper.)

Background & further reading

  • Carlini, Chien, Nasr, Song, Terzis, Tramèr, "Membership Inference Attacks From First Principles", IEEE S&P 2022 — LiRA, plus the methodological argument that attacks must be evaluated by TPR at low FPR (next entries).
  • Sablayrolles, Douze, Ollivier, Schmid, Jégou, "White-box vs Black-box: Bayes Optimal Strategies for Membership Inference", ICML 2019 — the Bayes-optimality argument; also shows the optimal white-box attack needs nothing beyond the loss, under the posterior model.

Two In-vs-Out Bells

For one record, you get two narrow bells: loss-when-in and loss-when-out. The target's observed loss is scored by which bell it sits closer to.

Key takeaway: Per-record in and out distributions make the test far sharper.

Theorem & proof

"Which bell is it closer to" has an exact closed form.

Theorem (LiRA's log-likelihood ratio is a quadratic). $$\log \Lambda(\ell) = \log\frac{\sigma_{\mathrm{out}}}{\sigma_{\mathrm{in}}} + \frac{(\ell - \mu_{\mathrm{out}})^2}{2\sigma^2_{\mathrm{out}}} - \frac{(\ell - \mu_{\mathrm{in}})^2}{2\sigma^2_{\mathrm{in}}} = A\ell^2 + B\ell + C,$$ with $A = \frac{1}{2\sigma^2_{\mathrm{out}}} - \frac{1}{2\sigma^2_{\mathrm{in}}}$, $B = \frac{\mu_{\mathrm{in}}}{\sigma^2_{\mathrm{in}}} - \frac{\mu_{\mathrm{out}}}{\sigma^2_{\mathrm{out}}}$, $C = \log\frac{\sigma_{\mathrm{out}}}{\sigma_{\mathrm{in}}} + \frac{\mu_{\mathrm{out}}^2}{2\sigma^2_{\mathrm{out}}} - \frac{\mu_{\mathrm{in}}^2}{2\sigma^2_{\mathrm{in}}}$.

Proof. $\log \mathcal{N}(\ell; \mu, \sigma^2) = -\tfrac12 \log(2\pi\sigma^2) - \frac{(\ell-\mu)^2}{2\sigma^2}$. Subtracting the out-density's log from the in-density's log cancels the $\tfrac12\log 2\pi$ terms and leaves the displayed expression; expanding both squares and collecting powers of $\ell$ gives $A, B, C$. $\blacksquare$

Corollary (equal variances: a $z$-test). If $\sigma_{\mathrm{in}} = \sigma_{\mathrm{out}} = \sigma$, then with $z(\ell) = \frac{\ell - \mu_{\mathrm{out}}}{\sigma}$ and effect size $d = \frac{\mu_{\mathrm{in}} - \mu_{\mathrm{out}}}{\sigma}$, $$\log \Lambda(\ell) = d\, z(\ell) - \frac{d^2}{2},$$ an increasing affine function of $\ell$ (when $d \gt 0$) — so LiRA reduces exactly to thresholding the record's standardized score.

Proof. With equal variances $A = 0$, and $$\log\Lambda = \frac{(\ell-\mu_{\mathrm{out}})^2 - (\ell-\mu_{\mathrm{in}})^2}{2\sigma^2} = \frac{(\mu_{\mathrm{in}} - \mu_{\mathrm{out}})\bigl(2\ell - \mu_{\mathrm{in}} - \mu_{\mathrm{out}}\bigr)}{2\sigma^2},$$ by the difference-of-squares identity. Substituting $\ell = \mu_{\mathrm{out}} + \sigma z$ gives $\frac{d\,(2\sigma z - (\mu_{\mathrm{in}} - \mu_{\mathrm{out}}))}{2\sigma} = d z - d^2/2$. $\blacksquare$

(Both verified against mia4-modern.html, Theorem 1 and Corollary 1.) The sharpness in the slide's picture is the effect size $d$: global bells have small $d$ because difficulty noise inflates $\sigma$; per-record bells remove that noise.

Label-Only Attacks

When the model returns only a label, Choquette-Choo and colleagues perturb the input and check whether the label survives. Members tolerate more perturbation, so robustness becomes the signal.

Key takeaway: Even label-only access leaks membership through robustness.

Slide figure: The slide reproduces Choquette-Choo et al. Fig. 1: attack accuracy on CIFAR-10 against training-set size for the confidence-vector attack, data augmentation, the gap attack, boundary distance, boundary plus translation, and confidence-vector against MemGuard. The label-only boundary attacks track the confidence-vector curve, so hiding scores does not remove the leak.

Definitions

Boundary distance. For a record $(x,y)$ classified correctly by $f_\theta$, $$d_\theta(x, y) = \min\bigl\{\, \lVert \delta \rVert_2 \;:\; f_\theta(x + \delta) \ne y \,\bigr\},$$ the radius of the largest perturbation the prediction survives. The label-only attack estimates $d_\theta$ by adversarial-perturbation search using label queries only, and scores "member" when the estimate is large. (As in mia4-modern.html, Definition 9.)

Theorem & proof

Proposition (linear case: boundary distance is confidence in disguise). For a binary linear classifier $h(x) = w^\top x + b$ with prediction $\mathrm{sign}(h(x))$: $$d_\theta(x) = \frac{|h(x)|}{\lVert w \rVert_2},$$ and if confidences follow the logistic model $p(x) = \sigma(h(x))$, then $d_\theta(x) = |\phi(p(x))| / \lVert w \rVert_2$ — a fixed monotone transform of the model's confidence, with $\phi$ the logit function.

Proof. The decision boundary is the hyperplane $H = \{u : w^\top u + b = 0\}$. The Euclidean distance from $x$ to $H$ is $|w^\top x + b| / \lVert w \rVert_2$: for any $u \in H$, $|h(x)| = |w^\top(x - u)| \le \lVert w\rVert_2\, \lVert x-u \rVert_2$ by Cauchy–Schwarz, with equality when $x - u \parallel w$; the minimising perturbation is $\delta = -h(x)\, w / \lVert w \rVert_2^2$. For the logistic model, $\phi(\sigma(t)) = t$, so $h(x) = \phi(p(x))$. $\blacksquare$

(Verified against mia4-modern.html, Proposition 4.) So at least in the linear case, the label-only attack recovers exactly the confidence score the API tried to hide — hiding confidences is not a defense.

Background & further reading

  • Choquette-Choo, Tramèr, Carlini, Papernot, "Label-Only Membership Inference Attacks", ICML 2021 — the perturbation-robustness attack, matching confidence-based attacks with label access only.

Average Accuracy Lies

A headline like fifty-five percent attack accuracy sounds harmless, but it hides that a handful of records leak with near certainty. The worst case is the real harm.

Key takeaway: Average accuracy can mask catastrophic per-record leakage.

Slide figure: The slide reproduces Carlini et al. (2022) Fig. 2: the ROC curve of the LOSS baseline on linear axes, where it appears to work, and on log-log axes, where it sits on the chance diagonal at low false-positive rates.

Definitions

Balanced accuracy is $\tfrac12(\mathrm{TPR} + 1 - \mathrm{FPR}) = \tfrac12(1 + \mathrm{TPR} - \mathrm{FPR})$ — an affine function of the advantage, so "55% accuracy" just means advantage $0.10$ on average over records. The average is indifferent to which records supply it: advantage $0.10$ is consistent with every record leaking slightly, and equally consistent with 10% of records leaking with near certainty while the rest are opaque. Privacy is a worst-case, per-person property; the next slide's metric is designed to see the tail rather than the mean.

TPR at Low FPR

The right metric fixes a tiny false positive rate, such as one in a thousand, and reads off the true positive rate: how many true members are still caught. On a log-log ROC curve this is the far left edge, where false positives are rare, and strong attacks like LiRA pull away exactly there. This is the evaluation standard Carlini and colleagues argued for.

Key takeaway: Judge attacks by their true positive rate at very low false positive rates, the left edge of the ROC curve.

Definitions

The metric. For an attack with ROC curve $\{(\mathrm{FPR}(\tau), \mathrm{TPR}(\tau))\}$, fix $\alpha$ small (typically $10^{-3}$ or $10^{-5}$) and report $$\mathrm{TPR}@\alpha \;=\; \mathrm{TPR}(\tau_\alpha), \qquad \tau_\alpha \text{ such that } \mathrm{FPR}(\tau_\alpha) = \alpha.$$ The rationale: an attacker who accuses at FPR $10^{-3}$ is credible — accusations are almost never wrong — so every percentage point of TPR there is a real, confident identification. High AUC or accuracy driven by the bulk of the ROC curve can coexist with zero confident identifications; $\mathrm{TPR}@\alpha$ cannot. (Metric and rationale as argued in Carlini et al., linked from the LiRA entry above; the same standard is used for the DP audit bound in §05.)

On log-log axes, random guessing ($\mathrm{TPR} = \mathrm{FPR}$) is the diagonal, and an attack's low-FPR behaviour — invisible in a linear plot, where the region $\mathrm{FPR} \le 10^{-3}$ occupies a thousandth of the axis — becomes the left half of the picture. Two attacks with the same AUC can differ by orders of magnitude in $\mathrm{TPR}@10^{-3}$. A DP guarantee also appears cleanly here: the bound $\mathrm{TPR} \le e^{\varepsilon}\,\mathrm{FPR} + \delta$ of §05 is (for $\delta \approx 0$) a line parallel to the diagonal at vertical offset $\varepsilon$ in log scale — a visual cap on the entire tail.

06 — What It Means

Sixth section. We connect attacks back to differential privacy: a real privacy bound provably limits any membership attack, and attacks let us audit that bound.

Key takeaway: Differential privacy and membership inference are two views of the same thing.

DP Caps the Attacker

Differential privacy, or DP, bounds how much one record can change the output: for datasets differing in one person, every outcome shifts by at most a factor $e^{\varepsilon}$ plus slack $\delta$. That very record-swap is what a membership attack exploits, so a genuine epsilon bound limits the success of any attacker, known or not.

Key takeaway: A real epsilon bound is a guarantee against every membership attack.

Definitions

Definition ($(\varepsilon,\delta)$-differential privacy). Datasets $D, D'$ are neighbouring if they differ in one record. A randomized mechanism $\mathcal{M}$ satisfies $(\varepsilon,\delta)$-DP if $$\Pr[\mathcal{M}(D) \in S] \;\le\; e^{\varepsilon}\, \Pr[\mathcal{M}(D') \in S] + \delta \qquad \text{for all neighbouring } D, D' \text{ and all measurable } S.$$ The quantifiers matter: every pair of neighbouring datasets, every event, both directions (the definition is symmetric in $D, D'$). $\delta = 0$ is pure $\varepsilon$-DP; $\delta \gt 0$ allows a small-probability failure and should be cryptographically small (e.g. $\delta \ll 1/n$).

Note the fit with this lecture: the two datasets $D$ and $D \cup \{x\}$ of the membership game are precisely a neighbouring pair, so DP is — by construction — a constraint on the two worlds the adversary must distinguish.

Theorem & proof

Theorem (DP as a hypothesis-testing bound; Wasserman–Zhou 2010, Kairouz–Oh–Viswanath 2015). Let $\mathcal{M}$ be $(\varepsilon,\delta)$-DP and consider any test of $H_0: \theta \sim \mathcal{M}(D)$ versus $H_1: \theta \sim \mathcal{M}(D \cup \{x\})$ with type-I error $\alpha$ (false positive rate) and type-II error $\beta$ ($= 1 - \mathrm{TPR}$). Then $$\alpha + e^{\varepsilon} \beta \;\ge\; 1 - \delta \qquad \text{and} \qquad \beta + e^{\varepsilon} \alpha \;\ge\; 1 - \delta.$$

Proof. Let $S$ be the rejection region (the event "$\hat b = 1$"), so $\Pr_1[S] = 1 - \beta$ and $\Pr_0[S] = \alpha$. Apply the DP inequality to the event $S$ with the neighbouring pair $(D \cup \{x\}, D)$: $$1 - \beta = \Pr_1[S] \le e^{\varepsilon} \Pr_0[S] + \delta = e^{\varepsilon}\alpha + \delta \;\Longrightarrow\; \beta + e^{\varepsilon}\alpha \ge 1 - \delta.$$ Apply it to the complement $S^c$ in the other direction: $$1 - \alpha = \Pr_0[S^c] \le e^{\varepsilon} \Pr_1[S^c] + \delta = e^{\varepsilon}\beta + \delta \;\Longrightarrow\; \alpha + e^{\varepsilon}\beta \ge 1 - \delta. \;\blacksquare$$

The proof quantifies over all rejection regions, i.e. over all adversaries — including ones not yet invented. That is the sense in which a genuine $\varepsilon$ is future-proof. (Verified against mia1-foundations.html, Theorem 3, and consistent with the lecture's tech supplement.)

Background & further reading

  • Wasserman, Zhou, "A statistical framework for differential privacy", JASA 2010 — the hypothesis-testing view of DP.
  • Kairouz, Oh, Viswanath, "The Composition Theorem for Differential Privacy", ICML 2015 — the tight two-inequality characterization used above.
  • Dwork, Kenthapadi, McSherry, Mironov, Naor, "Our Data, Ourselves: Privacy via Distributed Noise Generation", EUROCRYPT 2006 — where the $(\varepsilon,\delta)$ relaxation was introduced.

A Concrete Bound

Under (epsilon, delta)-DP, the best attacker's true positive rate is at most $e^{\varepsilon}$ times its false positive rate, plus delta. Small epsilon forces true positives down near false positives.

Key takeaway: DP turns into an explicit ceiling on the attack's ROC curve.

Theorem & proof

Corollary (ROC ceiling). Under $(\varepsilon,\delta)$-DP, every attack satisfies $$\mathrm{TPR} \;\le\; e^{\varepsilon}\, \mathrm{FPR} + \delta.$$ Proof. Rearrange $\beta + e^{\varepsilon}\alpha \ge 1 - \delta$ using $\mathrm{TPR} = 1 - \beta$, $\mathrm{FPR} = \alpha$. $\blacksquare$

Corollary (advantage ceiling). $\mathrm{Adv} = \mathrm{TPR} - \mathrm{FPR} \le (e^{\varepsilon} - 1)\,\mathrm{FPR} + \delta \le e^{\varepsilon} - 1 + \delta$. Proof. Subtract $\mathrm{FPR}$ from the ROC ceiling; then bound $\mathrm{FPR} \le 1$. $\blacksquare$

For pure DP ($\delta = 0$) this recovers the bound proved directly by Yeom et al. (Theorem 1 there): $\varepsilon$-DP implies $\mathrm{Adv} \le e^{\varepsilon} - 1$. (Corollaries verified against mia1-foundations.html, Corollaries 3–4; Yeom version against mia3-theory.html, Theorem 1.)

Auditing Flips the Attack

Run the strongest attack you have, read its true and false positive rates, and back out an empirical epsilon. If it exceeds the claimed epsilon, the implementation is broken; if it sits far below, the proof is just conservative. Either way the attack has become a measurement instrument, and auditing is now standard practice.

Key takeaway: Attack success inverts into an empirical privacy level that checks the claimed one.

Definitions

Empirical epsilon. Invert the ROC ceiling: if the mechanism were $(\varepsilon,\delta)$-DP, then every attack would obey $\mathrm{TPR} \le e^{\varepsilon}\mathrm{FPR} + \delta$. So any measured operating point $(\mathrm{FPR}, \mathrm{TPR})$ with $\mathrm{TPR} \gt \delta$ certifies $$\varepsilon \;\ge\; \hat\varepsilon \;=\; \log\!\left(\frac{\mathrm{TPR} - \delta}{\mathrm{FPR}}\right).$$ (One-line derivation from the corollary above; same formula as the lecture's tech supplement.) $\hat\varepsilon$ is a lower bound on the true privacy loss — an attack can only witness leakage, never certify its absence. In practice TPR and FPR are estimated from finitely many trials, so honest audits report $\hat\varepsilon$ computed from confidence-interval endpoints rather than point estimates.

The logic of the two outcomes, precisely: $\hat\varepsilon$ is a certified lower bound and the claimed $\varepsilon_{\mathrm{claim}}$ an upper bound, so a correct implementation always has $\hat\varepsilon \le \varepsilon_{\mathrm{true}} \le \varepsilon_{\mathrm{claim}}$.

  • $\hat\varepsilon \gt \varepsilon_{\mathrm{claim}}$: contradiction — the claimed bound is disproved. The audit is a formal counterexample (a bug certificate), typically pointing to broken clipping, mis-added noise, or accounting errors.
  • $\hat\varepsilon \ll \varepsilon_{\mathrm{claim}}$: consistent — either the analysis is conservative or the attack is weak; the audit cannot say which. Absence of witnessed leakage is not evidence of privacy.

Auditing in Practice

In practice you inject canaries, records crafted to be easy to detect, train the model, and attack the canaries. High detection means weak privacy, and recent methods audit in a single training run.

Key takeaway: Canary-based auditing is cheap enough to run on every model.

Slide figure: The slide reproduces Steinke, Nasr, and Jagielski Fig. 3: the 95%-confidence lower bound on epsilon as a function of the ideal epsilon implied by the fraction of correct canary guesses, for delta = 0, 1e-3, and 1e-2, with 1000 examples and no abstentions. More correct guesses yield a larger provable epsilon; the delta > 0 curves saturate.

Definitions

Canary. A record crafted to maximise the auditor's detection power — e.g. an out-of-distribution or randomly-labeled example — inserted into training with a known coin flip. Because the auditor chooses the record and knows the ground truth bit, the canary realizes the membership game under the auditor's control, with the strongest achievable signal.

Background & further reading

  • Steinke, Nasr, Jagielski, "Privacy Auditing with One (1) Training Run", NeurIPS 2023 — inserts many canaries with independent inclusion coins into a single run and turns membership guesses into an $\varepsilon$ lower bound via the DP–generalization connection, avoiding both retraining and the cost of group privacy; works black-box or white-box.

07 — Modern Models

Seventh section. We bring membership inference to large language models and diffusion models, and confront the live debate over whether it even makes sense at web scale.

Key takeaway: On foundation models, membership inference is powerful and contested.

Detecting Pretraining Data

Since 2023 the membership question is asked of foundation models: was this text in a language model's pretraining corpus? Shi and colleagues' Min-K percent scores text by its least likely tokens: members have few very-low-probability tokens, so averaging the most surprising ones flags seen text. The stakes are copyright and privacy at once.

Key takeaway: Min-K percent spots pretraining text through its rare, surprising tokens.

Definitions

Min-K% Prob. For a text $x = (x_1, \dots, x_T)$, let $L_t = \log p_\theta(x_t \mid x_{\lt t})$ be the token log-likelihoods. With $\alpha = K/100$ and $k = \lceil \alpha T \rceil$, the score averages the $k$ most surprising tokens: $$S_\alpha(x) = \frac{1}{k} \sum_{t \in \mathrm{Min}_k} L_t, \qquad \mathrm{Min}_k = \text{indices of the } k \text{ smallest } L_t.$$ Declare "member" when $S_\alpha(x)$ is high — seen text should have no very-low-probability tokens. No reference model, no shadow training: one forward pass.

Pretraining-data detection. The membership game instantiated at web scale: given a text $x$ and (black-box) access to an LLM $\theta$, decide whether $x$ was in the pretraining corpus $D$. Formally identical to the game of §01 — but three parameters have moved by orders of magnitude, and each breaks a tool from §02–§04: $n$ is billions of documents (each record's influence is minute), training is roughly one epoch (little overfitting to threshold on), and retraining even one "shadow" of the target costs millions of dollars (no shadow models, no LiRA at full scale). The rest of this section is about what survives.

Theorem & proof

Proposition (what Min-K% converges to). Treat the token surprisals of $x$ as draws from a document-specific distribution $F_x$. As $T \to \infty$, the Min-K% statistic converges almost surely to the tail functional $$S_\alpha(x) \;\longrightarrow\; \mathrm{CTE}_\alpha(F_x) = \frac{1}{\alpha}\int_{0}^{\alpha} F_x^{-1}(u)\, du,$$ the mean of the lowest $\alpha$-quantile of $F_x$ — a property of the document's own probability profile, in which membership appears only through its (small) shift of $F_x$.

Proof sketch. The empirical distribution of the $L_t$ converges uniformly to $F_x$ (Glivenko–Cantelli), hence empirical quantiles converge to population quantiles, and the average over the bottom $k = \lceil \alpha T\rceil$ order statistics converges to the corresponding tail expectation. $\blacksquare$ (Statement and sketch verified against mia5-llm.html, Proposition 5.)

The reading: Min-K% is an uncalibrated statistic — tail selection reweights the document's surprisal profile but does not divide out a per-record baseline as §04 demands. That is exactly the weakness the benchmark critiques below exploit.

Background & further reading

  • Shi, Ajith, Xia, Huang, Liu, Blevins, et al., "Detecting Pretraining Data from Large Language Models", ICLR 2024 — poses the pretraining-data detection problem, introduces Min-K% Prob and the WikiMIA benchmark (whose validity is questioned two entries below).

Diffusion Models Too

Image generators leave the same overfitting trace: members get lower denoising error, and heavily duplicated images leak most. The mechanism is identical, only the domain changes.

Key takeaway: Diffusion memorization grows with duplication, just like in language models.

Definitions

The diffusion membership score. For a diffusion model with noise-predictor $\epsilon_\theta$ and noise schedule $\bar\alpha_t$, the per-timestep statistic for image $x_0$ is the denoising error $$\varphi_t(x_0) = \mathbb{E}_{\epsilon \sim \mathcal{N}(0, I)}\Bigl[\bigl\lVert \epsilon - \epsilon_\theta\bigl(\sqrt{\bar\alpha_t}\, x_0 + \sqrt{1 - \bar\alpha_t}\, \epsilon,\; t\bigr) \bigr\rVert_2^2\Bigr],$$ i.e. the model's training loss at noise level $t$ — members are denoised better, especially at intermediate $t$. This is the loss-is-the-score attack of §02 transplanted verbatim; per-record calibration (§04) applies on top. (Definition as in mia4-modern.html, Definition 11.)

Background & further reading

  • Carlini, Hayes, Nasr, Jagielski, Sehwag, Tramèr, et al., "Extracting Training Data from Diffusion Models", USENIX Security 2023 — extracts near-copies of training images from Stable Diffusion and quantifies how duplication in the training set drives both extraction and membership leakage (the deck's duplication histogram is this paper's Figure 5).

Is MIA Well-Posed at Scale?

Duan and colleagues challenge the premise: on genuine web-scale language models, many published attacks barely beat random guessing once the evaluation is done carefully.

Key takeaway: At true web scale, many membership attacks barely beat chance.

Slide figure: The slide reproduces Duan et al. Fig. 1: AUC ROC of the reference-based attack against Pythia model size on Wikipedia, ArXiv, and HackerNews, for the normal and de-duplicated model suites. AUC stays between roughly 0.5 and 0.65 across sizes and is lower on de-duplicated models.

Background & further reading

The systematic study: Duan et al. evaluated five attack families — loss thresholding, reference-model calibration, Min-K%, zlib-compression calibration, and neighbourhood comparison — against Pythia and Pythia-dedup models from 160M to 12B parameters (plus GPT-Neo and OLMo), on MIMIR, a benchmark built by randomly splitting seven Pile domains into members and non-members (the random split is the methodological point — see "The Benchmark Trap"). Result: across attacks, models, and domains, AUC rarely exceeds 0.6 — near chance — with the GitHub domain the notable exception. (Numbers verified against mia5-llm.html, which tabulates the study.)

  • Duan, Suri, Mireshghallah, Min, Shi, Zettlemoyer, et al., "Do Membership Inference Attacks Work on Large Language Models?", COLM 2024 — the evaluation, the MIMIR benchmark, and the diagnosis picked up on the next slide.

Why Scale Breaks It

Two forces blunt the attack: a single pass over trillions of tokens leaves little overfitting, and members and non-members come from overlapping distributions. Skeptics conclude that web-scale attacks mostly measure distribution shift; the exceptions are rare, duplicated, or fine-tuning data, which still clearly leak. The question is unsettled as of 2025-26.

Key takeaway: Little overfitting plus overlapping data makes membership hard to read at web scale.

Background & further reading

Both forces are measured in Duan et al. (link on the previous entry):

  • Near-one-epoch training. In controlled-repetition experiments, attack performance was reported to increase roughly linearly with the number of effective epochs — and web-scale pretraining sits at the bottom of that curve, near one epoch, where the per-record fingerprint is weakest.
  • Overlapping members and non-members. On a natural (random-split) benchmark, non-members share a mean 7-gram overlap of 39.3% with members; on a temporally shifted split the overlap drops to 13.9%. On such shifted splits, apparent attack performance grows with model size (reference-attack AUC 0.602 at 160M rising to 0.796 at 12B) — the attack is reading the temporal shift, not membership.

(Numbers verified against mia5-llm.html, quoting Duan et al., COLM 2024.)

The Benchmark Trap

Many reported wins came from flawed splits: members drawn from older text, non-members from newer, post-cutoff text. The attack learned the date, not membership — blind date-guessing baselines that never query the model beat the published attacks.

Key takeaway: Always check whether a benchmark measures membership or a confound.

Slide figure: The slide reproduces Das, Zhang, and Tramèr Fig. 1 (appendix): a PCA plot of the WikiMIA benchmark in which members and non-members form two visibly separate clusters, computed without any access to a model.

Theorem & proof

The trap is a theorem about experimental design, not a quirk of particular attacks.

Proposition (a $\theta$-independent split measures text, not membership). Fix the released model $\theta$. Suppose benchmark members are drawn from a distribution $Q_1$ and non-members from $Q_0$, where $Q_1, Q_0$ are specified by a rule that does not depend on $\theta$ (e.g. a date cutoff). Then $$\sup_{\mathcal{A}} \mathrm{Adv}(\mathcal{A}) = \mathrm{TV}(Q_1, Q_0),$$ and the supremum is attained by a test that never queries $\theta$.

Proof. The adversary's view is $V = (x, \theta)$. Since the same fixed $\theta$ is served in both branches, its law is the point mass $\delta_\theta$ independent of the bit: $P_1 = Q_1 \otimes \delta_\theta$ and $P_0 = Q_0 \otimes \delta_\theta$. By the two-bells proposition (§02), $\sup_{\mathcal{A}} \mathrm{Adv} = \mathrm{TV}(P_1, P_0)$, and with a common second factor $$\mathrm{TV}(Q_1 \otimes \delta_\theta,\; Q_0 \otimes \delta_\theta) = \sup_S |Q_1(S) - Q_0(S)| = \mathrm{TV}(Q_1, Q_0).$$ By Neyman–Pearson the maximiser is $S^* = \{x : dQ_1/dQ_0(x) \gt 1\}$ — a function of $x$ alone. $\blacksquare$

So on a date-split benchmark, the blind baseline is optimal — the quantity being measured is a distance between two text corpora, unchanged if the model had never been trained. Conversely, a uniformly random split makes every $\theta$-blind test satisfy $\mathbb{E}[\mathrm{TPR}] = \mathbb{E}[\mathrm{FPR}]$ (each element lands in the training half with probability $\tfrac12$ independently of the test's output), so blind advantage is zero in expectation and any residual advantage is attributable to $\theta$. MIMIR is built this way. (Proposition, proof, and corollary verified against mia5-llm.html, Proposition 7 and corollary.)

Background & further reading

Empirically, blind baselines that never query the model beat the best published attacks on the popular benchmarks: on WikiMIA, blind AUC 99.0 versus 83.9 for the best published MIA (TPR at 5% FPR: 94.7 vs 43.2); Gutenberg, blind TPR@5%FPR 55.1 vs 18.8; BookMIA, blind AUC 91.4 vs 88.0. (Numbers verified against mia5-llm.html, quoting Tables 1–2 of the paper.)

  • Das, Zhang, Tramèr, "Blind Baselines Beat Membership Inference Attacks for Foundation Models", DATA-FM workshop at ICLR 2025 — date-extraction, bag-of-words, and $n$-gram classifiers beat published MIAs on all eight evaluated benchmarks.

Give the Attack Everything

Hayes and colleagues scaled LiRA to LLM pretraining with over a hundred reference models — the best-case attacker money can buy. It beats chance, but on many individual records it is still essentially a coin flip.

Key takeaway: Even the strongest known attack confirms the wall for LLM pretraining data.

Slide figure: The slide reproduces panel (a) of Hayes et al. Fig. 2: log-log ROC curves of the strong attack against six compute-optimally trained models from 10M to 1018M parameters, one epoch, 128 reference models; AUCs range from about 0.55 to 0.70.

Background & further reading

The experiment: scale LiRA — the §04 state of the art — to GPT-2-style models from 10M to 1B parameters trained on more than 20B tokens of C4, with 128 reference models. Headline AUCs stay modest and non-monotone in size: 0.592 (10M), 0.699 (85M), 0.689 (302M), 0.547 (489M), 0.654 (604M), 0.553 (1018M) — "effectiveness remains limited", AUC below 0.7 throughout. The sharper finding is per-record instability: across 127 replicas of the 302M target trained on the same data (mean LiRA AUC 0.752 ± 0.007 in that controlled setup), a two-sided exact binomial test of "this record's decision is a fair coin" at level 0.05 finds that at 0.1% FPR about 15.4% ± 0.6% of true positives are statistically indistinguishable from coin flips — 42.2% ± 0.9% counting highly unstable records — and members are more coin-flip-like than non-members. A good average ROC can hide chance-level behaviour on the very records the attack claims to identify. (Numbers verified against mia5-llm.html, quoting the paper's Figure 5 and surrounding text.)

  • Hayes, Shumailov, Choquette-Choo, Jagielski, et al., "Exploring the limits of strong membership inference attacks on large language models", NeurIPS 2025 — the strongest-attacker study answering whether prior negative results were attack-design artifacts or fundamental.

Ask About a Dataset, Not a Record

If one record is too weak a signal, aggregate: score every record in the suspect dataset and combine the weak signals into one statistical test that returns a p-value. Dataset inference can succeed where per-record MIA fails.

Key takeaway: Aggregating over a whole dataset turns weak per-record signals into a usable test.

Slide figure: The slide reproduces Maini et al. Fig. 1: the four stages of LLM dataset inference, from the victim supplying suspect and validation sets, through MIA feature aggregation and a learned linear model, to a t-test that delivers the p-value.

Definitions

Dataset inference. Replace the per-record game with a per-collection one: given a suspect collection $X = \{x_1, \dots, x_m\}$, test $H_0$: "$\theta$ was trained without $X$" against $H_1$: "$X \subseteq D$". Compute per-record membership scores on $X$ and on a held-out validation split from the same source, and run a two-sample test for a shift between the two score distributions; the output is a p-value. Even if each record's signal is an $\eta$-sized nudge, $m$ independent nudges aggregate to a detectable $\sqrt{m}\,\eta$ effect — the same aggregation logic as Homer's 500,000 SNPs in §01.

Background & further reading

  • Maini, Jia, Papernot, Dziedzic, "LLM Dataset Inference: Did you train on my dataset?", NeurIPS 2024 — the dataset-level test for LLMs, motivated precisely by the distribution-shift confounds that undermine per-record MIA benchmarks.

MIA in the Courtroom

Copyright suits ask exactly the MIA question: was our text in your training data? But a high membership score is not proof — without a known false-positive rate there is no valid null hypothesis, so making membership evidence court-ready is an open 2025-26 problem.

Key takeaway: A membership score without a calibrated false-positive rate cannot serve as proof.

Slide figure: The slide reproduces Zhang et al. Fig. 1: the training-data-proof setting, in which web data trains an LLM and, at deployment, a data creator presents proofs to a judge claiming the model used their data.

Background & further reading

The formal obstruction: to convince a third party, the data owner must show her attack's output is unlikely under the null — that the FPR is low against models not trained on her data. But sampling that null requires either knowing the exact training corpus (which is the fact in dispute) or retraining the foundation model without the disputed data (computationally prohibitive). Absent a null, any score threshold is uncalibrated — and by the benchmark-trap proposition above, an uncalibrated score may be measuring text properties rather than training. Zhang et al. make this argument and propose the alternative: sound evidence is possible when the owner plants randomized canaries in her data before publication (restoring a known null by design, as in DP auditing, §05).

  • Zhang, Das, Kamath, Tramèr, "Membership Inference Attacks Cannot Prove that a Model Was Trained On Your Data", IEEE SaTML 2025 — the impossibility argument for post-hoc training-data proofs, and the canary-based alternative.

08 — Defenses

Eighth section. We survey defenses, from cheap regularization to provable DP-SGD, and the accuracy cost each one carries.

Key takeaway: Defenses range from heuristic to provable, and all cost some utility.

Shrink the Gap

Since the attack feeds on overfitting, the first defenses reduce it: regularization like weight decay and dropout, early stopping before memorization sets in, and simply collecting more data.

Key takeaway: Reducing overfitting directly weakens the attack.

Definitions

Why this works, quantitatively: by the Yeom theorem of §02, the loss-threshold attack's advantage is exactly $\Delta / B$ — so every technique that shrinks the generalization gap $\Delta$ (weight decay, dropout, early stopping, more data) shrinks that attack's advantage in exact proportion. The limitation is the same theorem's fine print: $\Delta/B$ lower-bounds only one attack, and the zero-gap counterexample of §02 shows $\Delta = 0$ does not cap the others.

Heuristics Are Not Proof

Regularization raises the bar but offers no guarantee: a stronger attack may still succeed, and there is no bound on the worst-case record. It helps without being sufficient.

Key takeaway: Heuristic defenses help but never guarantee privacy.

Definitions

The distinction, formally: a guarantee bounds $\sup_{\mathcal{A}} \mathrm{Adv}(\mathcal{A}) = \mathrm{TV}(P_1, P_0)$ — the best of all adversaries, present and future. A heuristic lowers the advantage of the attacks we happened to try. The gap between the two is not rhetorical: §02's construction exhibits a model with zero train-test gap (every gap-based heuristic fully "succeeds") that a different adversary breaks perfectly. Only a mechanism-level bound on the two worlds' distinguishability — i.e. DP — controls the supremum.

DP-SGD: The Principled Defense

For a guarantee, train with DP-SGD: compute each example's gradient, clip it to a maximum length, add Gaussian noise to the sum, take the step, and track the spent epsilon. Clipping caps any single record's footprint and noise hides whether it was present, so the two worlds blur by construction, which is exactly the indistinguishability the attack tries to break. The price is accuracy: a smaller epsilon buys a stronger guarantee at a larger accuracy gap.

Key takeaway: DP-SGD enforces, by clip-then-noise, the very indistinguishability membership attacks target.

Definitions

DP-SGD update. With per-example gradients $g_i = \nabla_\theta \ell(\theta_t, z_i)$ over a batch of size $B$, clipping norm $C$, and noise multiplier $\sigma$: $$\mathrm{clip}(g, C) = g \cdot \min\Bigl(1, \frac{C}{\lVert g \rVert_2}\Bigr), \qquad \tilde g_t = \frac{1}{B}\Bigl(\sum_{i} \mathrm{clip}(g_i, C) + \mathcal{N}\bigl(0,\ \sigma^2 C^2 I\bigr)\Bigr), \qquad \theta_{t+1} = \theta_t - \eta\, \tilde g_t.$$ Clipping caps each record's contribution to the update at $C$ (its sensitivity); the Gaussian noise is scaled to that cap, making each step a Gaussian mechanism. (Definition as in mia4-modern.html, Definition 10.)

Theorem & proof

Theorem (privacy of DP-SGD; statement). Each noisy step is $(\varepsilon_{\mathrm{step}}, \delta_{\mathrm{step}})$-DP by the Gaussian-mechanism analysis, amplified by the random subsampling of the batch; composing across all $T$ steps with the moments-accountant analysis of Abadi et al. yields an overall $(\varepsilon, \delta)$-DP guarantee for the entire training run, with $\varepsilon$ growing like $O\bigl(q\sqrt{T \log(1/\delta)}/\sigma\bigr)$ for sampling rate $q$. The full proof (subsampled Rényi/moment bounds plus composition) is genuinely paper-length; see Abadi et al. below — not reproduced here.

The full chain from mechanism to attacker, each link proved earlier in the lecture:

  1. DP-SGD makes the training map $(\varepsilon,\delta)$-DP (previous entry), i.e. the two worlds $P_1, P_0$ of the game satisfy the DP inequality for every event;
  2. hence every membership test obeys $\mathrm{TPR} \le e^{\varepsilon}\mathrm{FPR} + \delta$ and $\mathrm{Adv} \le e^{\varepsilon} - 1 + \delta$ (§05 corollaries);
  3. and no post-processing escapes it:

Proposition (post-processing cannot help the attacker). For any function $h$ of the model — an API, a distilled model, an attack statistic — $$\mathrm{TV}\bigl(h(P_1),\, h(P_0)\bigr) \le \mathrm{TV}(P_1, P_0).$$

Proof. Any event $S$ about $h(\theta)$ is the event $h^{-1}(S)$ about $\theta$: $\Pr[h(\theta) \in S] = \Pr[\theta \in h^{-1}(S)]$ under both laws. The supremum defining the left side therefore ranges over a subset of the events available on the right. $\blacksquare$ (Verified against mia4-modern.html, Proposition 5; the same preimage argument shows the $(\varepsilon,\delta)$ guarantee itself survives post-processing.)

Since $\sup_{\mathcal{A}}\mathrm{Adv} = \mathrm{TV}(P_1,P_0)$ (§02), steps 1–3 bound every adversary that will ever exist, whatever it computes from the model.

Background & further reading

  • Abadi, Chu, Goodfellow, McMahan, Mironov, Talwar, et al., "Deep Learning with Differential Privacy", ACM CCS 2016 — DP-SGD and the moments accountant.

A Defender's Checklist

Before shipping: measure the train-test gap, run a LiRA-style audit, report the true positive rate at low false positive rates rather than average accuracy, and use DP-SGD when records are sensitive.

Key takeaway: Attack your own model before anyone else does.

Definitions

Each checklist line is one result from the lecture, applied: the gap bounds the basic attack exactly ($\mathrm{Adv} = \Delta/B$, §02); the LiRA audit approximates the per-record optimal test (§04), so it is the right instrument; $\mathrm{TPR}@10^{-3}$ is the metric that sees confident identifications (§04); and DP-SGD is the only item that bounds all attacks rather than the ones tried (§05, §07). Run the first three to measure, adopt the fourth to guarantee.

Key Takeaways

Membership inference asks whether a record was in training; Homer showed in 2008 that published averages already leak it; overfitting leaks it and loss is the simplest score; LiRA calibrates per record and we judge it at low false positive rates; DP bounds the attack while web-scale membership remains debated.

Key takeaway: Membership inference is the practical unit test of privacy.

Closing slide. The whole lecture comes down to one bit per record, in or out, and the goal of trustworthy machine learning is to keep that bit private.

Key takeaway: Keep the in-or-out bit private.
